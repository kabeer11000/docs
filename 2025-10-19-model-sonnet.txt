  🎯 Root Cause: Unnecessary Re-renders When Opening Comment Dialog

  The Problem

  The Solution (Applied)

  I used the ref-sync pattern to decouple the callback creation from state changes:

  Changes made:
  - ✅ Created showCommentDialogRef to track dialog state without triggering re-renders
  - ✅ Added useEffect to keep ref in sync with state (line 200-202)
  - ✅ Replaced state reads with ref reads in debouncedSelectionUpdate (lines 387, 397)
  - ✅ Changed dependency array to [] (line 414) - callback never recreates now

  Result:
  - No more editor re-renders when opening/closing comment dialog
  - Callback still checks if dialog is open via ref
  - Performance improvement ≈ eliminates unnecessary editor initialization

  - State is still used for DOM rendering (dialog visibility)

  - useEditor sees stable onSelectionUpdate → no reconfiguration

  The fix follows React best practices: use refs for side-effect values, state for render values!
